유튜브 듀얼 자막 Plus

유튜브 이중 자막 확장 프로그램이 안 될 때 — 이유와 확인할 것

마지막 확인: 2026-10-13

이중 자막 확장 프로그램이 갑자기 유튜브에서 아무것도 표시하지 않거나, 유튜브 자체 자막을 끄고 그 자리에 아무것도 띄우지 못한다면, 원인은 브라우저나 설정이 아닌 경우가 많습니다. 유튜브가 플레이어의 자막 요청 방식을 바꿨고, 예전 방식으로 보낸 요청에는 이제 빈 응답이 옵니다. 이 변경에 맞춰 업데이트되지 않은 확장은 계속 멈춰 있습니다. 유튜브 듀얼 자막 Plus는 유튜브 플레이어가 직접 보내는 요청에서 자막을 가져오기 때문에 지금 방식에서도 동작합니다.

왜 멈췄나

유튜브 플레이어는 이제 자기 자막 요청에 토큰을 붙입니다. 토큰이 없는 요청도 “성공”은 하지만, 돌아오는 내용이 비어 있습니다. 토큰 없이 직접 요청을 만드는 확장은 표시할 것을 아무것도 받지 못합니다.

이때 보이는 증상:

  • 자막이 분명히 있는 영상에서도 자막이 나오지 않습니다.
  • 확장이 자기 자막을 그리려고 유튜브 자막을 꺼 둔 경우, 자막이 하나도 남지 않습니다. 확장을 끄면 유튜브 자막이 돌아옵니다.

원인이 이것이라면 확장을 다시 설치하거나, 캐시를 지우거나, 브라우저를 바꿔도 소용이 없습니다. 같은 코드가 다시 설치될 뿐입니다. 개발자의 업데이트만이 고칠 수 있습니다.

먼저 확인할 것

모든 고장이 이 원인은 아닙니다. 확장을 포기하기 전에:

  1. 유튜브 탭을 새로고침하세요. 확장을 설치하거나 업데이트한 뒤에도, 이미 열려 있던 탭은 새로고침하기 전까지 예전 코드로 돌아갑니다.
  2. 영상에 자막이 있는지 확인하세요. 번역은 영상 자체의 자막으로 만듭니다. 자막이 없으면 번역할 것도 없습니다.
  3. 광고가 끝날 때까지 기다리세요. 저희 확장을 포함해 일부 확장은 광고 중에는 멈췄다가 영상이 시작되면 돌아옵니다.
  4. 크롬 웹 스토어 페이지에서 “업데이트” 날짜를 보세요. 1년이 넘었고 최근 리뷰에 “작동 안 함”이 이어진다면 다시 살아날 가능성은 낮습니다.

대신 고를 때 볼 것

  • 최근에 업데이트됐고, 최근 리뷰에서 잘 된다고 하는지.
  • youtube.com에만 접근 권한을 요청하는지 — “모든 웹사이트”가 아니라.
  • 계정이나 API 키를 설정할 필요가 없는지.
  • 자막을 불러오지 못하면 그렇다고 알려 주고, 유튜브 자막을 되돌려 주는지.

유튜브 듀얼 자막 Plus는 이렇게 처리합니다

  • 플레이어의 요청을 그대로 씁니다. 유튜브 자막 버튼으로 자막을 켜고, 플레이어가 보내는 요청을 토큰째 받아, 같은 요청으로 번역까지 가져옵니다.
  • 첫 번째 길이 막히면 두 번째 길로. 그 요청을 받지 못하면 유튜브의 스크립트 패널을 대신 읽습니다. 이 경우 원어만 표시되며, 팝업에 그렇게 알려 줍니다.
  • 무엇이 문제인지 알려 줍니다. 영상에 자막이 없을 때, 광고 중일 때, 고른 언어로 번역이 없을 때 — 빈 화면이 아니라 팝업에 메시지로 보여 줍니다.
  • 유튜브 자막을 되돌려 줍니다. 확장의 두 줄이 준비된 뒤에만 유튜브 자막을 끕니다. 준비되지 못하면 아무것도 빼앗지 않습니다.
  • 두 줄을 떨어뜨려 배치. 번역은 화면 위, 원어는 아래. 둘 다 아래로 모을 수도 있습니다. 언어·배치·크기·색은 영상이 바뀌어도 유지됩니다.
  • youtube.com에서만. 계정도, API 키도, 서버도 없고, 아무것도 수집하지 않습니다.

유튜브가 다시 바뀌지 않는다고 약속할 수 있는 확장은 없습니다. 할 수 있는 것은 실패를 숨기지 않고, 플레이어를 원래대로 두고, 업데이트되는 것입니다.
