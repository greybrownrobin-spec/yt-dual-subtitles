Dual subtitles extension not working on YouTube — why, and what to use

Last checked: 2026-10-16

If a dual subtitles extension suddenly shows nothing on YouTube — or turns YouTube's own captions off and shows nothing in their place — the cause is often not your browser or your settings. YouTube changed how its player fetches subtitles, and a request made the old way now comes back empty. An extension that has not been updated for that change stays broken. Dual Subtitles Plus takes the subtitles from the request YouTube's own player makes, so it works with the current method.

Why it stopped working

YouTube's player now adds a token to its own subtitle requests. A request without that token still “succeeds”, but the reply is empty. An extension that builds its own request without the token receives nothing to display.

What you see:

  • No subtitles appear, even on videos that clearly have them.
  • If the extension switched YouTube's captions off to draw its own, you are left with no captions at all. Turning the extension off brings YouTube's captions back.

When this is the cause, reinstalling the extension, clearing the cache or switching browsers will not help — you get the same code back. Only an update from the developer fixes it.

Check these first

Not every failure is this one. Before giving up on an extension:

  1. Reload the YouTube tab. After an extension installs or updates, tabs that were already open keep running the old copy until you reload them.
  2. Make sure the video has subtitles. The translation is made from the video's own subtitles. No subtitles, nothing to translate.
  3. Let the ad finish. Some extensions, including ours, pause during ads and come back when the video starts.
  4. Check the “Updated” date on the extension's Chrome Web Store page. If it is more than a year old and recent reviews say “not working”, it is unlikely to come back.

What to look for in a replacement

  • Updated recently, with recent reviews saying it works.
  • Asks for access only to the sites it works on — not “all websites”.
  • No account and no API key to set up.
  • When it cannot load subtitles, it says so and gives you YouTube's captions back.

How Dual Subtitles Plus handles this on YouTube

  • Uses the player's own request. It switches captions on through YouTube's caption button, picks up the request the player sends — token included — and gets the translation through that same request.
  • A second route if the first fails. If that request cannot be picked up, it reads YouTube's transcript panel instead. That route shows the original language only, and the popup says so.
  • Tells you what is wrong. No subtitles on the video, an ad playing, no translation for the chosen language — each shows as a message in the popup, not a blank screen.
  • Gives YouTube's captions back. YouTube's captions are switched off only once the extension's own lines are ready. If they never are, nothing is taken away.
  • Two lines, placed apart. Translation at the top of the video and original at the bottom, or both at the bottom. Languages, layout, size and colours stay set between videos.
  • Runs on YouTube; Netflix only after you turn it on. No access to other sites. No account, no API key, no server, nothing collected.

No extension can promise that YouTube will not change again. What it can do is fail visibly, leave your player as it was, and get updated.

Questions

Why did YouTube's captions disappear when I turned on a subtitle extension?
The extension switched YouTube's captions off so it could draw its own, then could not load any. Turn the extension off and YouTube's captions return.
Does reinstalling fix a broken dual subtitles extension?
Not when the cause is YouTube's change. Reinstalling gives you the same version. Only an update from the developer fixes it.
Does Dual Subtitles Plus work on Netflix?
Yes. Open the popup on a Netflix tab, press “Turn on for Netflix” and allow access — once. Netflix's own subtitles are used where they exist; otherwise Chrome translates on your device, where the language is supported.
